Projecte Destacat

matriculaciones.es En Producció

C# .NET Docker CI/CD (GitHub Actions) MySQL SEO & Monetització

Una plataforma web completa dissenyada per gestionar i analitzar matrícules. Més enllà del codi, aquest projecte és una demostració d'arquitectura professional d'extrem a extrem.

El que fa que aquest projecte destaqui:

  • Desplegament automatitzat: Ús de GitHub Actions per construir i desplegar contenidors Docker al meu propi servidor de producció.
  • Multidioma i Localització: Sistema preparat per català, castellà i anglès.
  • Optimització SEO avançada: Reestructuració per superar els requisits de Google AdSense (evitant el "thin content" i implementant estructures d'acordió).
  • Rendiment: Base de dades optimitzada i integració amb un mapa interactiu personalitzat.
