Sobre el projecte

Què és i
per què el vaig fer

Aquest projecte consisteix en la configuració i posada en marxa d'un servidor propi a casa, aprofitant maquinari disponible per desplegar-hi diversos serveis de manera autogestionada.

L'objectiu principal era aprendre de forma pràctica l'administració de servidors Linux, gestió de serveis en producció i implementació de solucions com Docker i còpies de seguretat automatitzades.

Objectius

Què volia aconseguir

  • Allotjar el portfoli web i altres pàgines de manera independent sense dependre d'hosting extern.

  • Configurar un sistema de notificacions push amb Gotify per monitoritzar l'estat dels serveis.

  • Aprendre Docker i docker-compose per desplegar serveis aïllats i fàcilment replicables.

  • Implementar còpies de seguretat automatitzades per protegir les dades crítiques.

Procés

Com ho vaig fer

PAS 01

Instal·lació del sistema operatiu

Instal·lació d'Ubuntu Server 24.04 LTS al maquinari disponible. Configuració inicial: usuaris, SSH, actualitzacions i firewall bàsic amb ufw.

sudo apt update && sudo apt upgrade -y sudo ufw allow OpenSSH sudo ufw enable

PAS 02

Configuració d'Apache i certificat SSL

Instal·lació d'Apache2 com a servidor web. Configuració de VirtualHosts per servir diverses pàgines des del mateix servidor. Certificat SSL amb Certbot (Let's Encrypt).

sudo apt install apache2 certbot python3-certbot-apache sudo certbot --apache -d isaacguisset.com

PAS 03

Desplegament de Docker i serveis

Instal·lació de Docker i docker-compose. Creació de fitxers docker-compose.yml per a cada servei. Desplegament de Gotify per a les notificacions push.

version: '3' services: gotify: image: gotify/server ports: - "8080:80" volumes: - ./data:/app/data

PAS 04

Monitorització i còpies de seguretat

Configuració de Cockpit per supervisar l'estat del servidor. Scripts de bash automatitzats amb cron per fer còpies de seguretat diàries dels serveis crítics.

# Crontab - còpia de seguretat diària a les 3:00 0 3 * * * /home/isaac/backup.sh >> /var/log/backup.log 2>&1
